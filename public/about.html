Layered audio

Music, ambience, and effects in one scene

A scene can contain multiple independent tracks. Let a calm score run under rain and fire, or combine battle music with repeating and occasional effects.

  • Add and remove tracks whenever the scene changes.
  • Name every layer so the mix remains easy to understand.
  • Mute a layer without deleting its setup.
  • Change track volume while keeping the scene volume intact.

Create a folder

Organize by location, mood, campaign, or encounter. Add an emoji and color.

Build a scene

Add one or more tracks, then set volume, loop, delay, and fades.

Choose the audience

Enable audio and play

Each listener enables audio once. Start, pause, resume, or stop from the panel.

Browsers require one user interaction before reliable audio playback. Each listener should press Enable audio once after joining the room.

⬆ Export before a move

Your library saves automatically in the current browser. Use Export to create a portable .aforge backup before clearing browser data or changing devices.

⬇ Import when you return

Use Import to restore a backup or convert a compatible .djinni, .json, or .txt collection into folders and scenes.

Good to know

Quick answers

Does audio continue when I close the extension popover?

Yes. Ambient Forge keeps playback running while the popover is closed, so it does not need to occupy your screen during play.

Can players set their own listening volume?

Yes. The game master controls the mix, while each player can adjust the master listening level on their own device.

Where are my folders and scenes saved?

They are saved automatically in that browser. Export an .aforge backup if you plan to clear browser data, switch browsers, or move to another device.

Can I prepare sounds without broadcasting them?

Yes. Select Only me to test privately, then switch to Everyone when you are ready for the table.
